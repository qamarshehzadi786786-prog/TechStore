# React Practice - Day 2

## What I Learned Today

### 1. React Props
Learned how to pass data from a parent component to a child component using props.

### 2. Reusable Components
Created a reusable `ProductCard` component that can display different products using different props.

### 3. Props Destructuring
Used destructuring to directly access `image`, `name`, `description`, and `price` props.

### 4. Dynamic Content
Used `{image}`, `{name}`, `{description}`, and `{price}` to display dynamic product information.

### 5. Tailwind CSS
Practiced styling product cards using Tailwind CSS classes such as spacing, shadows, borders, rounded corners, and hover effects.

### 6. Flexbox
Used Tailwind's `flex`, `gap`, `justify-center`, and `flex-wrap` to arrange product cards horizontally.

### 7. Product Section
Created a Featured Products section with a heading, description, and multiple product cards.
